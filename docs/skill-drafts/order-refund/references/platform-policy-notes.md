# 平台参考与本项目的简化边界

对应 Skill：0.1.1-draft；查阅日期：2026-09-29。这里只摘取可核实的简单原则，不合并三家平台为一套所谓通用规则。

“未发货不受退款截止时间限制”来自用户明确确认及本项目后端规则，不宣称上述平台所有商品均采用这一无例外约定。支付状态冲突处理、查询凭据和重试次数也是本项目契约，不归因于平台政策。

## 后续可以加入的简单业务规则（本版未启用）

1. 普通商品无理由退货：政策服务提供是否支持、截止时间、是否需要寄回；Agent 读取结果，资格通过不等于已退款。
2. 商品完好：只有取得有效的完好判断后才用于决策，不能单凭“拆封”二字拒绝；未知时进一步核实。
3. 简单例外：定制、鲜活易腐等是否支持无理由退货由政策字段判断，不让模型维护庞大类目清单。可参考 [京东退换货处理原则](https://help.jd.com/user/issue/439-1501.html)。
4. 质量或描述不符：单独进入售后核实流程，保留用户原因和证据，不直接套用无理由退货期限。需要新增可查询的证据及处理结果。

以上至少涉及新字段或流程。启用时需同步更新工具、案例、Role 和版本记录，不能仅往 Skill 加要求却继续用原工具假定已实现。若同次更换业务规则与 Skill，先在新规则上重跑无 Skill 基线，才能比较注入效果。

## 暂不参考

不实现优惠券与促销拆分、部分退款金额、定金预售、运费险理赔、赔偿计算、商家评级、跨境税费、极速退款资格和复杂争议举证。当前工具没有金额、支付渠道和入账状态，也不承诺原路退回或固定到账时长。
