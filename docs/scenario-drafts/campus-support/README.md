# 校园软件使用助手：轻结构场景

资料版本：0.2.0-draft；日期：2026-09-30；状态：v0.12.0 已接入只读工具、场景、可执行案例和规则评分；已完成一次无 Skill 真实模型运行，语义结论待用户复核。

这是虚构的“校园学习平台”，不是中国农业大学或任何真实平台的政策。所有限制、公告、时间和处理时限均为模拟数据，不应作为实际服务承诺。

## 使用边界

- 帮助条目与公告编号由只读工具作为证据编号返回，版本为 0.2.0-draft。
- 时间统一为北京时间（UTC+08:00）。案例固定 `as_of`，工具据此决定公告是否可见。
- 公告按更新记录的发布时间过滤，只能展示 `published_at <= as_of` 的版本；不能把恢复消息提前泄露给故障期间的案例。
- 查询某一历史时刻是否受影响，应同时核对症状、模块、对象及故障区间。故障区间采用左闭右开 `[开始, 恢复)`。
- 未发现匹配公告仅表示“暂无匹配的已发布公告”，不证明系统无故障。没有文档支持的原因或解决办法应标为未确认。
- 回答、整理资料、等待必要补充、说明无法确认都可以是合法结局，取决于当前轮用户目标。

## 请重点审查

1. 是否保留 20 MiB 文件限制、PDF/DOCX 格式，以及明确的边界值。
2. 账号锁定 15 分钟、导出超过 10 分钟建议核查的规则是否合适。
3. 评测标准是否允许多种正确表达，而不是匹配固定短语。
4. 回答正确性和效率是否分开统计，信息不足时是否允许合理追问。

## 后续实现要求（未实现）

工具结果的证据编号、发布时间、版本和内容写入 trace。评分标准保存在案例文件，不进入帮助检索。规则评分检查工具调用、证据取得和公告发布时间；回答语义标记 REVIEW，等待复核。
